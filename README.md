# Trek-Hike-Tracker
### Nima bu?  Trek &amp; Hike Tracker — Uzbekiston va dunyo bo'ylab hiking va trekking marshrut larini qo'shish, ko'rish, reyting berish va ulashish uchun platforma. Foydalanuvchilar o'zlari bosib o'tgan yo'llarni, fotolarni, qiyinlik darajasini va tavsiflarini qo'shadi. Boshqalar esa bu ma'lumotlardan safar rejalashtirish uchun foydalanadi.
